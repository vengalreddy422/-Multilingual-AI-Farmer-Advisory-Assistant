2. DETAILED TABLE DEFINITIONS & COLUMNS
--------------------------------------------------------------------------------

TABLE 1: `users` (Farmer Profiles & Authentication)
- `id` INTEGER PRIMARY KEY AUTOINCREMENT — Unique farmer ID.
- `username` TEXT UNIQUE NOT NULL — Login username (e.g. 'yaswanth7462').
- `password_hash` TEXT NOT NULL — SHA-256 cryptographic password hash.
- `full_name` TEXT — Farmer's full name (e.g. 'Yaswanth').
- `location` TEXT DEFAULT 'India' — Farmer's home village/district.
- `acres` REAL DEFAULT 2.0 — Landholding size in acres.
- `email` TEXT — Email address for automated PDF dispatch.
- `phone` TEXT — 10-digit mobile number for SMS/IVR authentication.
- `created_at` TEXT — Registration timestamp (YYYY-MM-DD HH:MM).

TABLE 2: `chat_history` (Advisory Conversation Sessions)
- `id` INTEGER PRIMARY KEY AUTOINCREMENT — Message ID.
- `user_id` INTEGER — Foreign key referencing `users.id`.
- `session_id` TEXT NOT NULL — UUID string grouping conversation turns.
- `role` TEXT NOT NULL — 'user' (farmer) or 'assistant' (AI agronomist).
- `content` TEXT NOT NULL — Spoken/written message or AI response.
- `created_at` TEXT — Exact timestamp (YYYY-MM-DD HH:MM:SS).

TABLE 3: `diagnostics_history` (Spatial Outbreak Radar Telemetry)
- `id` INTEGER PRIMARY KEY AUTOINCREMENT — Incident ID.
- `user_id` INTEGER — Foreign key referencing `users.id`.
- `timestamp` TEXT — Date & time of the leaf scan.
- `member_name` TEXT — Reporting farmer's name.
- `location` TEXT — Village/District name.
- `latitude` REAL — GPS Latitude coordinate (e.g. 13.5580).
- `longitude` REAL — GPS Longitude coordinate (e.g. 78.5020).
- `crop` TEXT — Affected plant (e.g. 'Tomato', 'Paddy').
- `diagnosis` TEXT — Identified disease name (e.g. 'Early Blight').
- `confidence` REAL — Neural network confidence score (e.g. 0.94).
- `prescription` TEXT — Dual Organic (ZBNF) + Chemical remedy.
- `severity` TEXT — Risk level ('🔴 High Risk', '🟡 Moderate').
